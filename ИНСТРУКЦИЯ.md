# Rename Tool — Инструкция для новичка

## 📋 Что это за программа?

**Rename Tool** — это программа для переименования кучу папок и файлов за один раз.

Например: у вас есть 100 папок с товарами с названиями типа `ART001`, `ART002` и т.д., а вам нужно переименовать их в штрихкоды `4600000000001`, `4600000000002`... Эта программа сделает это за пару секунд вместо того чтобы переименовывать каждую папку вручную.

**Программа работает без интернета** и без каких-либо токенов. Просто скачивайте и пользуйтесь.

---

## 🌍 Почему всё на английском?

Программа написана на PowerShell — это встроенный язык Windows. Интерфейс на английском потому что так проще с точки зрения программирования. Но не волнуйтесь — эта инструкция объяснит всё что нужно.

**Все сообщения программы будут на английском, но это не страшно:**
- `Done` = Готово
- `Error` = Ошибка
- `Select File` = Выбрать файл
- `Select Folder` = Выбрать папку
- `Start Renaming` = Начать переименование

---

## 🎯 Для чего нужна программа? Три режима

### Режим 1: Rename by List (по списку)

**Когда использовать:** У вас есть папки которые нужно переименовать по списку соответствия.

**Это универсальный режим для любого переименования:**
- Артикул → Штрихкод: `ART001` → `4600000000001`
- Старое название → Новое название: `СтарыйПроект` → `НовыйПроект`
- Код → Название: `A001` → `ОтделПродаж`
- Дата → Номер: `2023-12-01` → `Photo001`

**Пример:** Было `ART001` → Стало `4600000000001`

---

### Режим 2: Порядковые номера (Sequential Numbers)

**Когда использовать:** У вас есть папки с фотографиями, и внутри каждой папки нужно пронумеровать файлы по порядку (1, 2, 3...).

**Пример:** Было `foto_E.jpg`, `foto_Q.jpg` → Стало `1.jpg`, `2.jpg`, `3.jpg`

---

### Режим 3: Сбор в папки (Gather Folders)

**Когда использовать:** У вас куча фотографий разбросана в одной папке, а нужно сгруппировать их по серии.

**Пример:** Было `GW1157L5_Q.jpg`, `GW1157L5.jpg` → Создалась папка `GW1157L5` с этими файлами внутри

## 🔘 Все кнопки и функции — подробно

### 1. Rename Mode (выпадающий список)

**Что это:** Выбор режима работы программы.

**Три варианта:**
- `Rename by List` — для переименования папок по списку соответствия
- `Sequential Numbers` — для нумерации файлов
- `Gather Folders` — для группировки файлов

**Важно:** Как только вы выберете режим, окно изменится — покажутся только те кнопки которые нужны для этого режима.

---

### 2. Select File / Select Excel/CSV file

**Что это:** Кнопка для выбора файла с соответствием.

**Когда появляется:** Только в режиме `Rename by List`.

**Что делает:** Открывает окно где можно выбрать Excel или CSV файл.

**Какой файл нужен:** Файл где написано что на что заменить.

**Формат файла:**
```
Old Name    | New Name
ART001      | 4600000000001
ART002      | 4600000000002
```

> **Важно:** Названия колонок не важны! Программа просто берёт **первую колонку** как "что меняем" и **вторую** как "на что меняем".

**После выбора:** Рядом с кнопкой появится название выбранного файла зелёным цветом.

---

### 3. Load Suffix Config

**Что это:** Кнопка для выбора файла с приоритетами суффиксов.

**Когда появляется:** Только в режиме `Sequential Numbers`.

**Что делает:** Открывает окно где можно выбрать Excel файл с приоритетами суффиксов.

**Что такое суффикс:** Это часть названия файла после последнего подчёркивания `_`.
- `foto_E.jpg` — суффикс `_E`
- `foto_Q.jpg` — суффикс `_Q`
- `foto.jpg` — суффикса нет

**Зачем нужны приоритеты:** Программа нумерует файлы не как попало, а по порядку который вы зададите. Например сначала все файлы с `_E`, потом с `_Q`, потом без суффикса.

**Формат файла:**
```
Suffix     | Priority
_E         | 1
_Q         | 2
           | 3
```

---

### 4. Download Template (есть два варианта)

**Что это:** Кнопка для скачивания пустого шаблона Excel.

**Когда появляется:**
- В режиме `Rename by List` — шаблон для соответствия названий
- В режиме `Sequential` — шаблон для суффиксов

**Что делает:** Создаёт пустой Excel файл который уже правильного формата. Осталось только заполнить своими данными.

**Как использовать:**
1. Нажмите `Download Template`
2. Выберите где сохранить файл
3. Откройте файл в Excel
4. Заполните своими данными
5. Сохраните и закройте Excel
6. Теперь этот файл можно выбрать через `Select File` или `Load Suffix Config`

---

### 5. Select Folder

**Что это:** Кнопка для выбора папки с файлами.

**Когда появляется:** Во всех режимах.

**Что делает:** Открывает окно где можно выбрать папку.

**⚠️ ОЧЕНЬ ВАЖНО — какая именно папка нужна:**

#### Для режима `Rename by List`:

**Нужна папка с папками:**
```
📁 Товары/                    ← Вот эту выбираете!
├─ ART001/
│  └─ фото.jpg
├─ ART002/
│  └─ фото.jpg
└─ ART003/
   └─ фото.jpg
```

Если выбрать просто папку с файлами — программа не сработает! Нужно чтобы была **папка с папками**.

---

#### Для режима `Sequential Numbers`:

**Тоже нужна папка с папками:**
```
📁 Фото/                      ← Вот эту выбираете!
├─ Снимок1/
│  ├─ foto_E.jpg
│  ├─ foto_Q.jpg
│  └─ foto.jpg
├─ Снимок2/
│  ├─ foto_E.jpg
│  └─ foto.jpg
└─ Снимок3/
   └─ foto_Q.jpg
```

**Почему так:** Программа переименовывает файлы внутри каждой папки. Если выбрать просто папку с файлами — нечему будет нумероваться.

---

#### Для режима `Gather Folders`:

**А вот тут нужна просто папка с файлами:**
```
📁 Всефото/                   ← Вот эту выбираете!
├─ GW1157L5_Q.jpg
├─ GW1157L5.jpg
├─ GW1158L6_E.jpg
└─ GW1158L6.jpg
```

Программа сама создаст папки и рассортирует файлы.

---

### 6. Create Backup Copy (галочка)

**Что это:** Автоматическое создание резервной копии.

**Что делает:** Перед тем как начать переименование, программа полностью копирует вашу папку с новым названием.

**Зачем нужно:** Если что-то пойдёт не так — у вас останется оригинал. Можно просто удалить переименованное и вернуть копию.

**Как называется копия:**
```
ВашаПапка_backup_2024-08-05_14-30-15/
```

Название содержит дату и время чтобы вы не запутались.

**Где находится копия:** Рядом с оригинальной папкой, в том же месте.

**Важно:** Галочка стоит по умолчанию! **Рекомендуется всегда её оставлять включённой**, особенно если используете программу первый раз.

**Когда можно выключить:** Когда вы уже хорошо умеете пользоваться программой и уверены в своём файле соответствия.

---

### 7. START RENAMING (большая синяя кнопка)

**Что это:** Кнопка запуска переименования.

**Что делает:**
1. Проверяет что все файлы выбраны
2. Если включена галочка — создаёт резервную копию
3. Показывает окно подтверждения
4. Начинает переименование
5. Показывает результат

**До запуска:** Программа покажет что именно будет сделано и попросит подтвердить.

## 📁 Подробно о каждом режиме

### Режим 1: Rename by List (по списку)

#### Что делает

Переименовывает папки по списку соответствия "старое название → новое название".

**Это универсальный режим!** Подходит для любого переименования:
- Артикул → Штрихкод
- Старое название → Новое название
- Код → Название
- Дата → Номер
- Или любое другое соответствие

#### Пример

```
Было:                       После:
📁 Товары/               →   📁 Товары/
├─ ART001/                    ├─ 4600000000001/
│  └─ фото.jpg                │  └─ 4600000000001-1.jpg
├─ ART002/                    ├─ 4600000000002/
│  └─ фото.jpg                │  └─ 4600000000002-1.jpg
└─ ART003/                    └─ 0123456789012/
   └─ фото.jpg                   └─ 0123456789012-1.jpg
```

**Обратите внимание:** Не только папки переименовываются, но и файлы внутри!

---

#### Как подготовить файл соответствия

**Вариант 1: Скачать шаблон (рекомендуется)**

1. В программе выберите режим `Rename by List`
2. Нажмите `Download Template`
3. Сохраните файл
4. Откройте в Excel
5. Заполните:
   - **Первая колонка** — текущие названия папок (что меняем)
   - **Вторая колонка** — новые названия (на что меняем)

**Вариант 2: Создать самому в Excel**

Создайте Excel файл с двумя колонками:

| Old Name | New Name |
|----------|----------|
| ART001   | 4600000000001 |
| ART002   | 4600000000002 |
| ART003   | 0123456789012 |

> **Важно:** Названия колонок не важны! Можно назвать их как угодно. Программа просто берёт **первую** и **вторую** колонки.

**⚠️ ВАЖНО про ведущие нули:**

Если новые названия начинаются с нуля (например `0123456789012`), обычный Excel "съест" этот ноль и запишет как `123456789012`.

**Как исправить:**
1. Выделите **вторую колонку**
2. Нажмите правой кнопкой → Format Cells (Формат ячеек)
3. Выберите `Text` (Текстовый)
4. Нажмите OK
5. Теперь введите значение — ноль сохранится

**Было:**

```
ART001/

├─ foto2.jpg       →  4600000000001-2.jpg
└─ foto3.jpg       →  4600000000001-3.jpg
```

### Режим 2: Sequential Numbers

#### Что делает

Нумерует файлы внутри папок по порядку (1, 2, 3...) с учётом приоритетов.

#### Пример

```
Было:                           После:
📁 Фото/                    →   📁 Фото/
├─ Снимок1/                     ├─ Снимок1/
│  ├─ foto_E.jpg                │  ├─ 1.jpg  (это было _E)
│  ├─ foto_Q.jpg                │  ├─ 2.jpg  (это было _Q)
│  └─ foto.jpg                  │  └─ 3.jpg  (это было без суффикса)
└─ Снимок2/                     └─ Снимок2/
   ├─ foto_Q.jpg                   ├─ 1.jpg
   └─ foto_E.jpg                   └─ 2.jpg
```

**Важно:** Порядок нумерации зависит от приоритетов в конфиге!

---

#### Что такое суффикс

**Суффикс** — это часть названия файла после последнего подчёркивания `_`.

**Примеры:**
- `foto_E.jpg` → суффикс `_E`
- `foto_Q.jpg` → суффикс `_Q`
- `foto_RU.jpg` → суффикс `_RU`
- `foto.jpg` → суффикса нет (пустой)

---

#### Что такое приоритет

**Приоритет** — это число которое определяет в каком порядке переименовывать файлы.

**Правило:** Чем меньше число — тем раньше переименуется.

**Пример конфигурации:**
```
Suffix     | Priority
_E         | 1        ← переименуется первым
_Q         | 2        ← вторым
           | 3        ← третьим (пустой = без суффикса)
```

**Результат:**
1. Сначала все файлы с `_E` получат номера 1, 2, 3...
2. Потом все файлы с `_Q` получат следующие номера
3. Потом файлы без суффикса

---

#### Как подготовить файл конфигурации

**Вариант 1: Скачать шаблон (рекомендуется)**

1. В программе выберите режим `Sequential Numbers`
2. Нажмите `Download Template`
3. Сохраните файл
4. Откройте в Excel
5. Заполните:
   - Колонка `Suffix` — суффиксы из ваших файлов
   - Колонка `Priority` — приоритеты (числа)

**Вариант 2: Создать самому**

| Suffix | Priority |
|--------|----------|
| _E     | 1        |
| _Q     | 2        |
| _RU    | 3        |
|        | 4        |

**⚠️ ВАЖНО:**
- **Каждый приоритет должен быть уникальным!** Не может быть двух строк с приоритетом 1!
- Пустая строка в `Suffix` означает "файлы без суффикса"
- Если у файла есть суффикс которого нет в конфиге — он получит приоритет 999 (программа покажет предупреждение)

---

#### Пошаговая инструкция

1. **Подготовьте файл конфигурации** (см. выше)
2. **Запустите программу** `Rename-Tovari.ps1`
3. **Выберите режим** `Sequential Numbers`
4. **Нажмите** `Load Suffix Config` → выберите ваш Excel файл
5. **Нажмите** `Select Folder` → выберите **папку с папками**
6. **Проверьте галочку** `Create Backup Copy`
7. **Нажмите** `START RENAMING`
8. **Подтвердите** в окне подтверждения
9. **Дождитесь завершения**
10. **Посмотрите на предупреждения** (если есть)

---

#### Что может пойти не так

**Ошибка: Дубликаты приоритетов**

Если в конфиге два суффикса с одинаковым приоритетом:

```
ОШИБКА: Найдены дубликаты приоритетов!

Каждый приоритет должен быть уникальным.

Проблемные суффиксы:
  - Приоритет 2: _E, _RU
```

**Решение:** Исправьте конфиг — каждому суффиксу свой уникальный приоритет.

---

**Warning: Неизвестные суффиксы**

Если в файлах есть суффикс которого нет в конфиге:

```
⚠ НЕИЗВЕСТНЫЕ СУФФИКСЫ (получили приоритет 999):

- _RU (3 файл(ов))

Добавьте их в конфигурацию для правильного порядка.

=== ГОТОВЫЙ КОД ДЛЯ ДОБАВЛЕНИЯ ===

_RU | 5
```

**Решение:** Скопируйте готовый код и добавьте в Excel файл.

**Что значит "получили приоритет 999":** Файлы переименовались, но получили самый низкий приоритет. Программа не знала в каком порядке их нумеровать, поэтому сделала это последними.

---

### Режим 3: Gather Folders

#### Что делает

Группирует файлы в папки по базовому имени.

#### Пример

```
Было:                           После:
📁 Photos/                   →   📁 Photos/
├─ GW1157L5_Q.jpg               ├─ GW1157L5/
├─ GW1157L5.jpg                 │  ├─ GW1157L5_Q.jpg
├─ GW1158L6_E.jpg               │  └─ GW1157L5.jpg
├─ GW1158L6.jpg                 ├─ GW1158L6/
└─ document.pdf                 │  ├─ GW1158L6_E.jpg
                                    │  └─ GW1158L6.jpg
                                    └─ document.pdf
```

---

#### Как работает группировка

**Правило:** Программа берёт всё что находится **до первого подчёркивания `_` и создаёт папку с таким названием.

**Примеры:**
- `GW1157L5_Q.jpg` → папка `GW1157L5`
- `foto_E_big.jpg` → папка `foto`
- `document.pdf` → остаётся на месте (нет подчёркивания)

---

#### Пошаговая инструкция

1. **Запустите программу** `Rename-Tovari.ps1`
2. **Выберите режим** `Gather Folders`
3. **Нажмите** `Select Folder` → выберите **папку с файлами** (не с папками!)
4. **Проверьте галочку** `Create Backup Copy`
5. **Нажмите** `START RENAMING`
6. **Подтвердите**
7. **Дождитесь завершения**

---

#### Особенности

**Если папка уже существует:**

Если программа пытается создать папку `GW1157L5` а такая уже есть — она покажет предупреждение и пропустит эти файлы.

**Решение:** Переименуйте или удалите существующую папку и запустите программу снова.

## ⚠️ Сообщения об ошибках — что они означают

### "Select folder first!"

**Перевод:** Сначала выберите папку!

**Причина:** Вы нажали `START RENAMING` не выбрав папку.

**Решение:** Нажмите `Select Folder` и выберите нужную папку.

---

### "Select CSV file first!"

**Перевод:** Сначала выберите CSV файл!

**Причина:** Вы выбрали режим `Rename by List` но не выбрали файл соответствия.

**Решение:** Нажмите `Select File` и выберите Excel/CSV файл.

---

### "Select suffix config file first!"

**Перевод:** Сначала выберите файл конфигурации суффиксов!

**Причина:** Вы выбрали режим `Sequential` но не выбрали файл с приоритетами.

**Решение:** Нажмите `Load Suffix Config` и выберите Excel файл.

---

### "Folder 'XXX' already exists!"

**Перевод:** Папка 'XXX' уже существует!

**Причина:** Режим `Gather` пытается создать папку которая уже есть.

**Решение:** Удалите или переименуйте существующую папку.

| Пронумеровать фото внутри папок | `Sequential` | Excel с суффиксами + папка с папками |
| Сгруппировать фото по серии | `Gather` | Просто папка с файлами |

---

## 💡 Советы

1. **Первый раз — всегда с бэкапом!** Включите галочку `Create Backup Copy`.
2. **Тестируйте на копии!** Скопируйте папку и потестируйте на копии.
3. **Проверьте файл конфигурации!** Откройте Excel и убедитесь что всё правильно.
4. **Ведущие нули!** Вторая колонка должна быть текстового формата.
5. **Уникальные приоритеты!** Никаких дубликатов в конфиге суффиксов.
6. **Правильная папка!** Для `Rename by List` и `Sequential` нужна папка с папками. Для `Gather` — просто папка.

---

## 🆘 Если не работает

### Программа не запускается

**Возможно:** У вас заблокировано выполнение PowerShell скриптов.

**Решение:** Щёлкните правой кнопкой на файл → `Свойства` → `Разблокировать`

---

### Файлы не переименовываются

**Проверьте:**
1. Правильный ли режим выбран?
2. Правильная ли папка выбрана? (для Rename by List и Sequential нужна папка с папками!)
3. Правильный ли файл конфигурации?
4. Нет ли опечаток в названиях?

---

### Новое название без ведущего нуля

**Причина:** Вторая колонка не текстового формата.

**Решение:** Откройте Excel → выделите вторую колонку → Format Cells → Text → введите значение заново.

---

### Как восстановить из бэкапа

**Бэкап находится рядом с оригинальной папкой:**
```
📁 Папка/
📁 Папка_backup_2024-08-05_14-30-15/
```

**Как восстановить:**
1. Удалите переименованную папку (если нужно)
2. Переименуйте бэкап: уберите `_backup_...`
3. Готово!

## 📝 Подготовка файлов — чеклист

### Для режима Rename by List:

- [ ] Excel файл с двумя колонками (что меняем | на что меняем)
- [ ] Вторая колонка в текстовом формате (если есть ведущие нули)
- [ ] Папка с папками (не просто папка!)
- [ ] Названия в первой колонке совпадают с названиями папок

### Для режима Sequential:

- [ ] Excel файл с колонками `Suffix` и `Priority`
- [ ] Приоритеты уникальные (нет дубликатов!)
- [ ] Папка с папками (не просто папка!)
- [ ] Суффиксы в Excel совпадают с суффиксами в файлах

### Для режима Gather:

- [ ] Просто папка с файлами
- [ ] В именах файлов есть подчёркивания (если хотите группировать)
