# Rename Tool - Инструкция пользователя

## 📋 Общее описание

**Rename Tool** — это приложение для массового переименования папок и файлов. Работает без интернета и AI-токенов. Подходит для обработки товаров, фотографий, документов.

**Три режима работы:**
1. **Штрихкод (Stokmann)** — переименование папок по артикулу
2. **Последовательная нумерация** — нумерация файлов по порядку
3. **Сбор в папки** — группировка файлов по базовому имени

### Выбор режима (Rename Mode)

| Режим | Когда использовать | Что нужно выбрать |
|-------|-------------------|------------------|
| **Barcode (Stokmann)** | Переименовать папки по артикулу → штрихкод | Excel/CSV файл + папка с товарами |

> **Важно:** Интерфейс меняется автоматически! Для каждого режима показываются только нужные кнопки.

## 📁 Режим 1: Штрихкод (Stokmann)

### Что делает

Переименовывает папки по артикулу из Excel/CSV файла:

```
До:                      После:
├─ ART001/          →    ├─ 4600000000001/
│  └─ фото.jpg           │  └─ 4600000000001-1.jpg
├─ ART002/          →    ├─ 4600000000002/
│  └─ фото.jpg           │  └─ 4600000000002-1.jpg
```

Файлы внутри папок нумеруются как: `штрихкод-1.jpg`, `штрихкод-2.jpg` и т.д.

### Подготовка файла соответствия

**Формат Excel файла:**

| Articul | Barcode |
|---------|---------|
| ART001  | 4600000000001 |
| ART002  | 4600000000002 |
| ART003  | 0123456789012 |

> **Важно:** Колонка `Barcode` должна быть в текстовом формате чтобы сохранять ведущие нули!

### Как скачать шаблон

1. Выберите режим **Barcode (Stokmann)**
2. Нажмите **Download Template**
3. Сохраните файл `template-articul-barcode.xlsx`
4. Заполните своими данными

### Пошаговая инструкция

1. ✅ Выберите режим **Barcode (Stokmann)**
2. 📊 Нажмите **Select File** → выберите Excel/CSV с артикулами
3. 📁 Нажмите **Select Folder** → выберите папку с товарами
4. □ Поставьте галочку **Create Backup Copy** (рекомендуется)
5. 🚀 Нажмите **START RENAMING**

### Поддерживаемые форматы файлов

- **Excel:** `.xlsx`, `.xls`
- **CSV:** `.csv` (любой разделитель)

## 🔢 Режим 2: Sequential Numbers

### Что делает

Нумерует файлы внутри папок по порядку (1, 2, 3...) с учётом приоритета суффиксов:

```
До:                           После:
├─ Папка1/                →   ├─ Папка1/
│  ├─ foto_E.jpg              │  ├─ 1.jpg       (суффикс _E, приоритет 1)
│  ├─ foto_Q.jpg              │  ├─ 2.jpg       (суффикс _Q, приоритет 2)
│  └─ foto.jpg                │  └─ 3.jpg       (без суффикса, приоритет 3)
├─ Папка2/                →   ├─ Папка2/
│  ├─ foto_Q.jpg              │  ├─ 1.jpg
│  └─ foto_E.jpg              │  └─ 2.jpg
```

### Как это работает

1. **Суффиксы** — это часть имени файла после последнего подчёркивания `_`
   - `foto_E.jpg` → суффикс `_E`
   - `foto_Q.jpg` → суффикс `_Q`
   - `foto.jpg` → суффикс пустой `""`

2. **Приоритет** — определяет порядок переименования
   - Чем меньше число — тем раньше переименуется
   - Файлы с суффиксом приоритета 1 получат номера 1, 2, 3...
   - Файлы с суффиксом приоритета 2 получат следующие номера

3. **Пример приоритетов:**
   ```
   Суффикс | Приоритет
   --------|----------
   _E      | 1
   _Q      | 2
   ""      | 3
   ```

   Результат: сначала переименуются `_E`, потом `_Q`, потом без суффикса.

### Подготовка конфигурации суффиксов

**Формат Excel файла:**

| Suffix | Priority |
|--------|----------|
| _E     | 1        |
| _Q     | 2        |
| _RU    | 3        |
|        | 4        |

> **⚠️ ВАЖНО:**
> - **Каждый приоритет должен быть уникальным!**
> - Суффиксы с меньшим номером переименуются первыми
> - Неизвестные суффиксы получат приоритет 999 (будет предупреждение)

### Как скачать шаблон

1. Выберите режим **Sequential Numbers**
2. Нажмите **Download Template**
3. Сохраните файл `template-suffix-priority.xlsx`
4. Заполните своими суффиксами и приоритетами

### Пошаговая инструкция

1. ✅ Выберите режим **Sequential Numbers**
2. 📊 Нажмите **Load Suffix Config** → выберите Excel с суффиксами
3. 📁 Нажмите **Select Folder** → выберите папку с **папками** файлов
4. □ Поставьте галочку **Create Backup Copy** (рекомендуется)
5. 🚀 Нажмите **START RENAMING**

### Что будет если...

| Ситуация | Что произойдёт |
|----------|---------------|
| Дубликаты приоритетов (два суффикса с приоритетом 1) | ❌ **ОШИБКА** — покажет какие суффиксы конфликтуют |
| Неизвестный суффикс в файлах (нет в конфиге) | ⚠️ **Warning** — покажет список неизвестных с готовым кодом для добавления |
| Корректная конфигурация | ✅ Переименование без предупреждений |

## 📂 Режим 3: Gather Folders

### Что делает

Группирует файлы в папки по базовому имени (до первого `_`):

```
До:                           После:
📁 Photos/                →   📁 Photos/
├─ GW1157L5_Q.jpg            ├─ GW1157L5/
├─ GW1157L5.jpg              │  ├─ GW1157L5_Q.jpg
├─ GW1158L6_E.jpg            │  └─ GW1157L5.jpg
├─ GW1158L6.jpg              ├─ GW1158L6/
└─ other.txt                 │  ├─ GW1158L6_E.jpg
                              │  └─ GW1158L6.jpg
                              └─ other.txt
```

### Правило группировки

- Базовое имя — всё **до** первого подчёркивания `_`
- Если подчёркивания нет — файл остаётся как есть

Примеры:
- `GW1157L5_Q.jpg` → базовое имя `GW1157L5`
- `foto_E_big.jpg` → базовое имя `foto`
- `document.pdf` → базовое имя `document.pdf` (не перемещается)

### Пошаговая инструкция

1. ✅ Выберите режим **Gather Folders**
2. 📁 Нажмите **Select Folder** → выберите папку с файлами
3. □ Поставьте галочку **Create Backup Copy** (рекомендуется)
4. 🚀 Нажмите **START RENAMING**

### Особенности

- Если папка с таким именем уже существует — покажет предупреждение и пропустит группу
- Файлы без подчёркивания остаются на месте

## 🛡️ Безопасность

### Create Backup Copy

**Всегда включено по умолчанию!**

- Создаёт полную копию папки перед переименованием
- Имя бэкапа: `ИмяПапки_backup_гггг-мм-дд_чч-мм-сс`
- Если что-то пошло не так — можно восстановить из бэкапа

**Пример:**
```
Товары/ → Товары_backup_2024-08-05_14-30-15/
```

## ⚠️ Предупреждения и ошибки

### Дубликаты приоритетов

**Сообщение:**
```
ОШИБКА: Найдены дубликаты приоритетов!

Каждый приоритет должен быть уникальным.

Проблемные суффиксы:
  - Приоритет 2: _E, _RU

Исправьте конфигурацию (уберите дубликаты или измените приоритеты)
и попробуйте снова.
```

**Решение:** Измените приоритеты чтобы они были уникальными.

### Неизвестные суффиксы

**Сообщение:**
```
Done!

Files renamed: 15
Errors: 0

⚠ НЕИЗВЕСТНЫЕ СУФФИКСЫ (получили приоритет 999):

- _RU (3 файл(ов))
- _Q (1 файл(ов))

Добавьте их в конфигурацию для правильного порядка.

=== ГОТОВЫЙ КОД ДЛЯ ДОБАВЛЕНИЯ ===

_RU | 5
_Q  | 6
```

**Решение:** Скопируйте готовый код и добавьте в Excel файл конфигурации.

## 💡 Советы

1. **Всегда используйте Backup** — первый раз тестируйте на копии
2. **Проверяйте суффиксы** — посмотрите warning после первого запуска
3. **Уникальные приоритеты** — никаких дубликатов в конфиге
4. **Текстовый формат для штрихкодов** — иначе ведущие нули пропадут

---

## 🐛 Если что-то пошло не так

1. **Проверьте бэкап** — он в той же папке где исходная
2. **Посмотрите ошибку** — в сообщении обычно написано что не так
3. **Проверьте формат файлов** — Excel должен быть `.xlsx` или `.xls`
4. **Проверьте путь** — в путях не должно быть спецсимволов
