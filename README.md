# Rename Tool — массовое переименование папок и файлов

Небольшая программа для Windows, которая переименовывает сотни папок и файлов за несколько секунд — вместо ручного переименования по одному.

**Работает без интернета, без установки и без каких-либо токенов.** Написана на PowerShell (встроен в Windows) с обычным оконным интерфейсом.

---

## 🎯 Три режима работы

### 1. Rename by List — переименование по списку

Папки переименовываются по списку соответствия из Excel или CSV файла (первая колонка — что меняем, вторая — на что меняем).

Универсальный режим для любого соответствия:
- Артикул → Штрихкод: `ART001` → `4600000000001`
- Старое название → Новое название
- Код → Название

Файлы внутри папок тоже переименовываются: `4600000000001-1.jpg`, `4600000000001-2.jpg`...

### 2. Sequential Numbers — порядковые номера

Файлы внутри каждой папки нумеруются по порядку (1, 2, 3...) с учётом приоритетов суффиксов (`_E`, `_Q`, `_RU`...), которые задаются в Excel-конфиге.

```
Было:                  Стало:
Снимок1/               Снимок1/
├─ foto_E.jpg          ├─ 1.jpg
├─ foto_Q.jpg          ├─ 2.jpg
└─ foto.jpg            └─ 3.jpg
```

### 3. Gather Folders — сбор в папки

Разбросанные файлы группируются в папки по базовому имени (всё до первого подчёркивания `_`).

```
Было:                  Стало:
├─ GW1157L5_Q.jpg      ├─ GW1157L5/
├─ GW1157L5.jpg        │  ├─ GW1157L5_Q.jpg
├─ GW1158L6_E.jpg      │  └─ GW1157L5.jpg
└─ GW1158L6.jpg        └─ GW1158L6/
                          ├─ GW1158L6_E.jpg
                          └─ GW1158L6.jpg
```

## 🚀 Как запустить

1. Скачайте файл `Rename-Tovari.ps1`
2. Щёлкните по нему правой кнопкой → **«Выполнить с помощью PowerShell»**

**Если Windows блокирует запуск скачанного файла:**
правый клик по файлу → `Свойства` → галочка `Разблокировать` → OK.

**Требования:** Windows + установленный Excel (для чтения Excel-файлов; CSV работает и без Excel).

---

## 🛡️ Безопасность

- Перед переименованием программа показывает, что будет сделано, и просит подтверждение
- Галочка **Create Backup Copy** включена по умолчанию — создаётся полная резервная копия папки (с датой и временем в имени), из которой всё можно восстановить
- Кнопка **Download Template** создаёт пустой Excel-шаблон нужного формата
